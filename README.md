# 🏛️ Viaggio della Coscienza - Fenomenologia dello Spirito

Un'esperienza web interattiva a scorrimento che attraversa il percorso evolutivo della coscienza secondo Hegel, con paralleli storici tra i periodi filosofici e storici.

## 📚 Struttura del Progetto

Il progetto contiene tre file principali:

1. **index.html** - Struttura HTML dell'esperienza interattiva
2. **styles.css** - Stili CSS per il design e le animazioni
3. **script.js** - Logica JavaScript per l'interattività

## 🎨 Caratteristiche

### Fasi della Coscienza

**1. Coscienza (Preistoria)**
- Certezza sensibile - Preistoria
- Percezione - Paleolitico
- Intelletto - Neolitico

**2. Autocoscienza (Età antica)**
- Servitù e signoria - Età antica
- Stoicismo e scetticismo - Ellenismo
- Coscienza infelice - Medioevo

**3. Ragione (Illuminismo)**
- Ragione osservativa - Rinascimento
- Ragione attiva - Età moderna
- Individualità in sé per sé - Età contemporanea

### Funzionalità Interattive

- ✨ **Scorrimento smooth** con animazioni di apparizione
- 📜 **Timeline verticale** che collega tutte le fasi
- 🎯 **Highlight** automatico delle sezioni in vista
- 📊 **Barra di progresso** che mostra la posizione nel viaggio
- ⌨️ **Navigazione da tastiera** (freccie su/giù)
- 📱 **Supporto touch** per dispositivi mobili
- ✨ **Particelle fluttuanti** per un effetto atmosferico
- 🎭 **Effetto parallax** sui numeri delle fasi

## 🚀 Come Utilizzare

### Metodo 1: Open con Navigatore Web

1. Apri il file `index.html` con il tuo browser web preferito
2. Scorri verso il basso per iniziare il viaggio

### Metodo 2: Local Server (Consigliato)

Per un'esperienza ottimale con tutte le funzionalità:

```bash
# Utilizza Python
python -m http.server 8000

# Oppure Node.js
npx serve
```

Poi apri `http://localhost:8000`

## 🎯 Guida all'Esperienza

1. **Scorri** verso il basso per iniziare
2. **Osserva** i vari stadi della coscienza con i loro paralleli storici
3. **Clicca** su ogni scheda per espandere il contenuto dettagliato
4. **Usa le frecce** o lo swipe per navigare tra le sezioni
5. Guarda la **barra di progresso** in basso per sapere dove ti trovi

## 🎨 Design

- **Palette colori**: Blu notte con accenti dorati (#ffd700)
- **Font**: Georgia serif per un look accademico e elegante
- **Stile**: Glassmorphism con sfondo semi-trasparente
- **Animazioni**: Fluttuazione, transizioni smooth, reveal elements

## 📖 Riferimenti

Basato sulla struttura concettuale di:
- *Fenomenologia dello Spirito* (1807) di Georg Wilhelm Friedrich Hegel
- La progressione della coscienza da fenomeno a noumeno

## 🎭 Note del Design

Ogni fase include:
- Un numero identificativo
- Un titolo in caratteri dorati
- Icone animate
- Contesto storico specifico
- Contenuto esplicativo dettagliato

La linea temporale verticale collega visivamente tutti i periodi, evidenziando il continuum storico-philosophico proposto da Hegel.
